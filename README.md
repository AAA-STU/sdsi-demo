# SDSI Agentic AI Hackathon — Central Repo

Developer track. Build your agent here and raise a **pull request** — the AI
evaluator reads your PR diff, not the whole repo.

## How to participate
1. Create a branch: `git checkout -b <your-alias>`
2. Build under `submissions/<your-alias>/`
3. Push and open a PR titled `[track] Your Name — use-case-id`
4. Paste the PR URL into your dashboard on the microsite.

See `usecases/` for the briefs.
